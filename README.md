## Overview
A simple (in implementation and hopefully in use, too) growable queue of heap allocated strings.
Read the `queue.h` header file as a reference for the struct fields, enum codes and list of functions, along with info about the functions.
For now, only the StringQueue queue is implemented.
All filenames, enum names, enum values, function names, struct names, struct field names, along with the folder structure, are subject to change in later commits, as I'm not currently sure what would be best.

## Dependencies

I'm not aware of any dependency other than standard C libraries.

## Compiling with the library

Either include the `queue.c` source file directly in your source or include the header file and add the source file in your compile command or build system. The source file has an include guard.
